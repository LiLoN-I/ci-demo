# ci-demo

Учебный проект с функциями сложения, вычитания и умножения.

## Требования
- Python 3.12 и выше.

## Установка
1. Клонировать репозиторий.
2. Установить зависимости (при наличии).

## Запуск
python -m unittest discover -v

## Возможности
- Сложение чисел (add).
- Вычитание чисел (subtract).
- Умножение чисел (multiply).
